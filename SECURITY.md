# Security Policy

## Supported Versions

| Package | Version | Supported |
| :--- | :--- | :---: |
| `@typescript-calendar-lib/core` | 0.1.x | :white_check_mark: |
| `@typescript-calendar-lib/cli` | 0.1.x | :white_check_mark: |
| `@typescript-calendar-lib/tui` | 0.2.x | :white_check_mark: |
| `@typescript-calendar-lib/react` | 0.1.x | :white_check_mark: |
| `@typescript-calendar-lib/web` | 0.1.x | :white_check_mark: |
| `@typescript-calendar-lib/svelte` | 0.2.x | :white_check_mark: |
| Any other version | — | :x: |

This project is in early development (0.x). Only the latest minor release of each package receives security patches.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through [GitHub Private Vulnerability Reporting](https://github.com/nazozokc/typescript-calendar-lib/security/advisories/new).

**Please do NOT report security vulnerabilities through public GitHub issues.**

### What to expect

- **Acknowledgment**: within 72 hours
- **Status update**: within 7 days
- **Fix timeline**: depends on severity; critical issues will be prioritized
- Once a fix is released, a public Security Advisory will be published on GitHub

### Scope

This policy covers all packages published under the `@typescript-calendar-lib/*` scope in this monorepo. Security issues in upstream dependencies should be reported to the respective maintainers, but please also notify us so we can evaluate the impact on this project.
